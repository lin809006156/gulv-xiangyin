# 古律象音

> 观身边之物起卦，为每一卦生成一段心音。
> 传统文化与艺术创作，**不含任何预测功效**。

以《周易》卦象与古代律吕文化为灵感，把「起卦」与「听音」合成一次体验：
观物成卦，卦生五声，每一段心音都由该卦的调式、律、乐器与六爻阴阳结构推导而来，
随卦象不同而不同。

## 二、核心设计：一次编写，三端同源

```
core/          ← 唯一真相源（卦象 / 文献 / 作曲 / 合成 / 渲染）
  ├─→ web/core/          （由 scripts/sync-core.js 同步）
  ├─→ miniprogram/core/  （同上）
  └─→ android/app/src/main/assets/public/  （由 npx cap sync 同步）
```

`core/` 分层如下，各层职责单一、可单独验证：

| 模块 | 职责 |
| ---- | ---- |
| `classics.js` | 文献依据：卦象取象、乐器归属、五音清浊、物象映射的出处 |
| `data.js` | 六十四卦、物象库、别名表、调式映射 |
| `hexagram.js` | 起卦三法、卦象推导、卦辞与解读 |
| `hexagram-texts.js` | 六十四卦详解（爻辞、彖传、大象、京房八宫纳甲，由脚本生成） |
| `music.js` | 作曲：调式、律、速度、六爻旋律轮廓、力度弧线、伴奏层 |
| `render.js` | 数字音频渲染器：八种乐器的物理频谱合成 |
| `player.js` | 播放适配层：网页 / 小程序 / 应用三端统一接口 |
| `recognize.js` | 物象归一层：口语与自由描述归一到物象库 |

## 三、内容原则：凡定义必注出处

项目对「定义类」内容（卦象取象、乐器归属、五音清浊、物象映射）设有硬性要求：
**每一条都必须在 `core/classics.js` 中有对应条目**，并注明出处等级与取舍理由。

| 字段 | 含义 |
| ---- | ---- |
| `src` | `classic` 典籍原文 / `later` 后世类书 / `modern` 当代类推 |
| `cite` | 引文原句（`classic` 与 `later` 必填） |
| `reason` | 取象理由（`modern` 必填） |
| `alt` | 异说与取舍说明（凡改动归属必填，说明依据） |

主要依据：《白虎通疏证·礼乐》《礼记·乐记》《说卦传》《周易·系辞》《梅花易数》等。
改动物象映射必须先查证、再改 `classics.js`、再跑校验脚本。

**边界**：五音配脏腑属古代音律理论，本项目**不宣称任何医疗或疗效**；
全站不出现「转运 / 改运 / 预测 / 占卜断事」等表述。

## 四、声音引擎

### 4.1 音色即五音的实质维度

角、徵、宫、商、羽不只对应音高，各有专属音色（`core/timbre.js`）。
以 Goertzel 频带分析量化验证：有音高的乐器上，五音清浊单调递增（《乐记》疏：宫至浊 → 羽最清），
相对提升 ≥ 25% 且绝对 ≥ 2.5pp。

### 4.2 乐器

八音（柷敔 / 钟 / 弦 / 鼓 / 箫 / 埙 / 管 / 磬）各配一卦（《白虎通·礼乐》引《乐记》），
以 `core/render.js` 的物理频谱参数实时合成，非预置音频采样。

### 4.3 伴奏层

中国传统「丝竹」体制：宫音踏板与和声垫承底，支声应和，柷敔落板与鼓点定节。
伴奏严格不出调，五声音阶在主旋律与伴奏上均成立。

### 4.4 即兴连播

每次播放按「卦象身份 + 时间种子 + 随机变体」现场编曲：同一卦每次听来不同，
而卦象身份（调式 / 律 / 主音 / 音色 / 六爻旋律与节奏）恒定。
跨轮宏曲式八段一循环：呈示 · 应和 · 加花 · 隔凡 · 分裂 · 压上 · 换头 · 再现；
隔凡与压上为移宫，旋律、踏板与和声垫同步平移，不越移宫边界，避免半音撞音。

### 4.5 音层

可选的疗愈九频（索菲吉奥频率）与自然五层（雨 / 鸟 / 篝火 / 风 / 溪），
每层独立 VCA，可随时开关。全部关闭时，播放与纯净五声逐位一致。

## 五、波形台：暗调展厅

三维风洞空间中，卦象为青铜金属板堆叠而成的立体卦体，声波以「丝缕」形态自左右气口涌入。

| 环节 | 实现 |
| ---- | ---- |
| 卦体 | **正交画法**：正面水平矩形 + 顶面/端面平行四边形；立体感来自三面光照，不依赖投影除法 |
| 材质 | 拉丝纹理、磨损划痕、上下倒角、暖金边缘自发光、地面暖光倒影 |
| 气口 | 拉丝钢金属环 + 强光内芯 + 虹膜细弧 + 向内体积光锥 + 地面光斑 |
| 云雾 | **湍流丝缕**：拖尾折线由旋度噪声场推动，以固定轨道位复现「收腰分瓣」形态；宽描边经离屏画布整层高斯模糊做出体积感，细亮芯保留丝缕锐度；近卦象处转暖金 |
| 深度 | 前后景分层与投影缩放；镜面地面有雾影倒影 |
| 性能 | 帧率自适应：连续 30 帧均耗 >34ms 自动减丝，<20ms 拉满；性能档另降分辨率与模糊半径 |

## 六、界面

- **三栏结构**（音乐栏居中）：起卦 / 音乐 / 学易。
- **视觉**：iPhone 液态玻璃拟态（半透明磨砂面板、悬浮胶囊标签栏、分层高光与阴影）；
  三套皮肤（纸本 / 流光 / 夜航）仅通过 CSS 变量切换，即时生效。
- **浮动播放栏**：播放时自底部标签栏上方滑出的同轴胶囊，含曲名、播放/暂停、循环、音量，
  与音乐栏双向同步。
- **液态按压动效**：触点高光 + 涟漪环 + 带过冲的回弹，只动 transform / opacity / filter。
- **学易栏**：易之生成、八卦速查、六十四卦全表、按上下卦找卦、起卦与卜筮、五音十二律、
  爻位与变卦、八音配卦、所据典籍。

## 七、工程结构

```
hexagram-music/
├── core/                 # 唯一真相源
├── web/                  # PWA 网页版
├── miniprogram/          # 微信小程序
│   └── pages/            #   起卦 / 详情 / 卦历
├── android/              # Capacitor 壳工程
├── scripts/              # 同步、校验、端到端测试、构建脚本
├── lab/                  # 方案对比台（开发用）
├── capacitor.config.json
└── package.json
```

**修改 `core/` 后必须执行 `node scripts/sync-core.js`**，保持 `web/core/` 与 `miniprogram/core/` 一致。

## 八、构建

```bash
npm run sync                  # 同步 core 到 web/ 与 miniprogram/
node scripts/gen-icons.js     # 生成各尺寸图标
npx cap sync android          # 同步 web 资源进原生工程
cd android && ./gradlew assembleDebug
```

环境要求：Node ≥ 18、JDK 17、Android SDK（iOS 需 macOS + Xcode）。
