参考图 vs 实装 · 波形台声波云雾

左为参考图（AI 生成的概念图），右为本项目的实装截图（真实浏览器 + 真实出声实时演算，非贴图）。 目标不是像素级复刻，而是把参考图的四件套做出来：气口、金属卦体、湍流丝缕、镜面地面。

参考 概念图

暗调展厅：左右各一个发亮的竖长开口，浓密的冰白云雾自两侧涌入、在中央青铜卦象处收腰分瓣， 雾里有暖金丝线，地面是镜面并映出模型与光。

实装 学易心音 · 卦象立体

同一套做法：金属环气口（拉丝钢 + 虹膜 + 体积光锥）、青铜金属板卦象（拉丝 + 磨损 + 倒角 + 暖金辉光）、 湍流丝缕自左右涌入并贴着卦体上下缘走、近处转暖金、镜面地面有雾影与模型倒影。

气口：参考图左右的发亮开口 → 实装为拉丝钢金属环 + 强光内芯 + 虹膜细弧 + 向内体积光锥 + 地面光斑
烟雾形态：参考图的自两侧涌入、在卦象处收腰分瓣 → 实装用「轨道位 lane」+「收腰函数」复现同样的形，湍流用旋度噪声做出卷曲与分叉
体积感：参考图的蓬松云体 → 实装用「离屏画布 + 整层高斯模糊」得到柔软体积，芯层保持锐利
颜色：冰白主体 + 暖金内核 → 实装按到卦体的距离在冰白↔暖金之间插值，模型还会向雾溢光
金属卦体：参考图的拉丝金属板 → 实装为四段渐变正面 + 18 条拉丝纹 + 磨损划痕 + 上下倒角 + 暖金自发光
镜面地面：参考图映出模型与光 → 实装有模型暖光倒影带、卦体倒影与雾的翻折倒影
参考图的「电影级体积光 + 逐像素自阴影」需 GPU 光线步进（方案 D），纯 2D 做不到；本版取的是丝缕路线（方案 B）
