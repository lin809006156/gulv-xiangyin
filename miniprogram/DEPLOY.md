## 〇、播放后端与网页版的分工

小程序端的播放实现**不在** `core/` 里，而在 `miniprogram/utils/audio-backend-mini.js`
（InnerAudioContext + WAV 落盘）；网页端另有一份 `web/js/audio-backend-web.js`
（Web Audio）。`core/player.js` 只是引擎，负责编排，不含任何平台代码。

因此：

- 改小程序播放逻辑 → 只动 `miniprogram/utils/`，网页端一行不受影响；
- 改网页播放逻辑 → 只动 `web/js/`，小程序端一行不受影响；
- 改共享逻辑（编曲、循环、渲染） → 动 `core/player.js`，两端同时生效（应有之义）。

校验命令：`npm run verify:layering` —— 自动检查 `core/` 下没有平台 API、
后端文件各在其位、平台分支数不超限。

## 一、波形台与网页版同源

小程序端与网页版的波形台**共用同一份渲染代码**（`core/viz-stage.js`）：

- 改画面效果只需改 `core/viz-stage.js` 一处，两端同时生效；
  改完记得跑 `node scripts/sync-core.js` 同步到 `miniprogram/core/`。
- 两端唯一的差异是**频谱来源**：网页版取自 Web Audio 的 `AnalyserNode`；
  小程序没有该节点，改由乐谱按播放位置推算（`core/player.js` 的 `genPos`）。
- 校验命令：`npm run verify:stage` —— 在「小程序式」环境下跑一遍共享核心，
  确认画面不是一片空白。

## 二、代码同步

```bash
node scripts/sync-core.js     # 同步（等价于 npm run sync）
node scripts/check-sync.js    # 自检（等价于 npm run check:sync）
```

同步 13 个核心文件到 `web/core/` 与 `miniprogram/core/`。小程序端只依赖 `miniprogram/core/`，
改根目录 `core/` 而不同步，小程序不会变化。
`check-sync` 会逐文件比对三处，任何一处对不上即报错退出 —— 提交前跑一次就不会漏同步。

> `web/core/` 与 `miniprogram/core/` 是**构建时生成**的副本，**不入版本库**。
> 克隆后先跑 `npm install`（会自动同步），或手动 `npm run sync`。

新增核心文件时需同时登记三处：`scripts/sync-core.js` 的 `FILES`、`web/index.html` 的
`<script>` 标签（注意依赖顺序）、`core/require-shim.js` 的 `MAP`。

## 四、音频播放策略（两级降级）

1. **首选 `InnerAudioContext`**：把渲染好的 WAV 写入 `wx.env.USER_DATA_PATH` 再播放。
   好处是支持后台播放、进度精确、可分享文件。
2. **降级 `wx.createWebAudioContext()`**：写盘失败时实时播放
   （延迟反馈网络模拟混响、声道分离模拟声像）。

## 五、发布流程

> **上传老版本会不会有影响？** 不会，但要按下面两条处理：
>
> - **只上传过、没发布**：直接传新版即可。旧的「开发版本」若还在审核中，先在
>   版本管理里撤回，免得占位。新版版本号必须**大于**之前上传过的任何一个版本号。
> - **已经发布过**：老版本用户仍在用，新版要重新提审；审核通过发布后，用户下次打开
>   会自动更新到新版，微信会保留一个历史版本以备回退。审核备注里写清「移除拍照识象功能、
>   更名古律象音」即可。
>
> 另有两处与公众平台相关的独立事项，见第六节。

1. 同步核心代码（见第一节）。
2. 微信开发者工具 → 导入项目 → 目录选 `miniprogram/`，AppID 选 `wxc98a73689cb1ca7a`。
3. 编译，用「预览」扫码在真机验证：起卦三法、播放、卦历、卦象详情。
4. 「上传」→ 版本号填与 GitHub tag 一致的版本（如 `1.3.0`），项目备注写明本次变更。
5. 公众平台 <https://mp.weixin.qq.com> → 管理 → 版本管理 → 提交审核。
6. 审核通过后回到版本管理 → 发布（可定时发布）。

## 六、上架合规要点

- **类目**：选「传统文化 / 国学」。占卜算命类目必被拒审。
- **文案红线**：不出现「转运 / 改运 / 预测命运 / 吉凶占断 / 消灾 / 祈福改命」等表述。
- **功效宣称**：五音之说属传统音乐与养生观念，不可宣称医疗或疗效；页面底部免责声明不可删除。
- **隐私**：当前版本不采集、不上传任何用户数据，也不使用摄像头与相册，
  无需在隐私保护指引中声明设备权限。
  若此前上传的版本声明过「摄像头 / 相册」，请到「设置 → 用户隐私保护指引」把这两项删掉，
  保持与实际功能一致。

## 七、公众平台上的两项独立事项

这两项**不在代码里**，必须登录公众平台手工改：

1. **小程序名称**：若平台上仍显示旧名（卦象心音 / 学易心音），
   到「设置 → 基本设置 → 名称」提交改为「古律象音」。
   名称修改**需要审核**，且每年修改次数有限，建议尽早处理。
2. **用户隐私保护指引**：按第五节处理，删除已不再使用的设备权限声明。
