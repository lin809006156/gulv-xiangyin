## 一、每次改动后的发布流程（6 步）

### 1 · 本地同步（一条命令）

```bash
cd C:\Users\图书馆五楼\WorkBuddy\1\hexagram-music
node scripts/sync-core.js
```

输出应为「共同步 22 个文件 → web\core / miniprogram\core」。
小程序端**只认 `miniprogram/core`**，改根目录 `core/` 而不同步 = 小程序没变。

### 2 · 打开微信开发者工具，导入项目

- 目录（项目路径）选 `C:\Users\图书馆五楼\WorkBuddy\1\hexagram-music\miniprogram`
- AppID 选自己的 **`wxc98a73689cb1ca7a`**（已写进 `project.config.json`，导入时自动带出）
- 基础库建议 3.5.5 及以上

### 3 · 编译 + 手机预览自测

点「编译」，再用「预览」扫码在真机上过一遍：

| 要点 | 通过标准 |
| ---- | ---- |
| 起卦三法 | 每日一卦 / 拍照识象 / 数字起卦都能出卦 |
| 播放 | 点播放有五声（手机静音键要关，否则听不到） |
| 卦历 | 记录能存住、能回看 |
| 卦象详情 | 爻辞、象曰、京房八宫、此卦之音都正常 |
| 免责 | 页面底部固定免责声明在 |

### 4 · 若动过 `core/`，重新上传云函数（关键）

**云函数不会跟着小程序代码走**，必须单独传：

开发者工具 → 文件树里右键 `cloudfunctions/vision` → **「上传并部署：云端安装依赖」**。

> 拍照识象依赖这个云函数转发多模态模型；不重传的话，小程序里识别可能报错或用旧版逻辑。

### 5 · 上传

工具右上角「上传」→ 填：

- **版本号**：`1.1.0`（与 GitHub 的 tag `v1.1.0` 保持一致，便于追溯）
- **项目备注**：写清楚这次改了什么，例如「波形台声波云雾重做 + 卦体正交重画 + 核心更新」

### 6 · 公众平台：提交审核 → 发布

1. 打开 <https://mp.weixin.qq.com> → 登录 → 左侧「管理」→「版本管理」
2. 在「开发版本」里找到刚上传的版本 → 点「提交审核」
3. 填「版本描述」和「审核备注」（备注可写：传统文化与艺术创作类应用，不含预测功能）
4. 审核通过后回到「版本管理」→ 点「发布」（可设为定时发布）

## 三、上架红线（务必照做）

**类目**：必须选「传统文化 / 国学」类目。
**不要选占卜算命类目**，必被拒审。

**文案红线**：全程不得出现「转运」「改运」「预测命运」「吉凶占断」「消灾」「祈福改命」等表述。
当前实现已全部规避，改文案时请一并检查。

**功效宣称**：五音之说属传统音乐与养生观念，**不可宣称任何医疗或疗效**。
页面底部固定免责声明不可删除。

**隐私**：拍照识象会用到相机与相册，隐私指引里要写明「仅用于拍照识象，不额外存储、不上传第三方」。

**域名**：开发阶段可在工具里勾「不校验合法域名」，**上线前必须配置服务器域名白名单**。
