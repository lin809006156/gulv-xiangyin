# 微信小程序端 · 开发与发布说明

> AppID：`wxc98a73689cb1ca7a`　项目名：古律象音　基础库：3.5.5
> 核心代码 `miniprogram/core/` 由 `scripts/sync-core.js` 从仓库根目录同步而来，**根目录 `core/` 是唯一真相源**。

---

## 一、代码同步

```bash
node scripts/sync-core.js
```

同步 20 个核心文件到 `web/core/` 与 `miniprogram/core/`。小程序端只依赖 `miniprogram/core/`，
改根目录 `core/` 而不同步，小程序不会变化。

新增核心文件时需同时登记三处：`scripts/sync-core.js` 的 `FILES`、`web/index.html` 的
`<script>` 标签（注意依赖顺序）、`core/require-shim.js` 的 `MAP`。

## 三、音频播放策略（两级降级）

1. **首选 `InnerAudioContext`**：把渲染好的 WAV 写入 `wx.env.USER_DATA_PATH` 再播放。
   好处是支持后台播放、进度精确、可分享文件。
2. **降级 `wx.createWebAudioContext()`**：写盘失败时实时播放
   （延迟反馈网络模拟混响、声道分离模拟声像）。

## 四、发布流程

1. 同步核心代码（见第一节）。
2. 微信开发者工具 → 导入项目 → 目录选 `miniprogram/`，AppID 选 `wxc98a73689cb1ca7a`。
3. 编译，用「预览」扫码在真机验证：起卦三法、播放、卦历、卦象详情。
4. 「上传」→ 版本号填与 GitHub tag 一致的版本（如 `1.2.0`），项目备注写明本次变更。
5. 公众平台 <https://mp.weixin.qq.com> → 管理 → 版本管理 → 提交审核。
6. 审核通过后回到版本管理 → 发布（可定时发布）。

## 五、上架合规要点

- **类目**：选「传统文化 / 国学」。占卜算命类目必被拒审。
- **文案红线**：不出现「转运 / 改运 / 预测命运 / 吉凶占断 / 消灾 / 祈福改命」等表述。
- **功效宣称**：五音之说属传统音乐与养生观念，不可宣称医疗或疗效；页面底部免责声明不可删除。
- **隐私**：当前版本不采集、不上传任何用户数据，也不使用摄像头与相册，
  无需在隐私保护指引中声明设备权限。
